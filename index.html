Vegetation Risk Monitor

Geospatial ETL pipeline and interactive dashboard that identifies wildfire risk from tree canopies near power lines. A Dagster pipeline ingests GeoJSON, computes proximity via sjoin_nearest in a metric CRS, scores risk from distance, canopy height, and NDVI, and loads results into PostGIS. A FastAPI service exposes GeoJSON endpoints with bounding-box spatial filtering; a React + Deck.GL frontend renders color-coded risk zones with filters and tooltips.

Multi-Chain HD Wallet Address Generator

Multi-chain address generation service built on HD wallets. A FastAPI application generates BIP39 mnemonics, derives BIP44 master extended keys for Bitcoin, Ethereum, and Dogecoin, and exposes REST endpoints to derive fresh child addresses on demand. Keys and derivation indexes are persisted in PostgreSQL via SQLAlchemy, with Alembic migrations managing schema evolution.
