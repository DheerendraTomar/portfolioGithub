# Python Developer Portfolio

A modern, responsive portfolio website designed for a Python Developer. Built with HTML, CSS, and JavaScript, featuring a "Liquid Glass" aesthetic with smooth animations and a clean layout.

## Features

-   **Modern Design**: Glassmorphism effects, gradient text, and animated background blobs.
-   **Responsive Layout**: Fully responsive design that works on desktops, tablets, and mobile devices.
-   **Interactive Elements**: Smooth scrolling, hover effects, and a dynamic mouse-following background.
-   **Sections**:
    -   **Hero**: Introduction and call to action.
    -   **About**: Professional summary.
    -   **Skills**: Grid display of technical skills.
    -   **Experience**: Alternating vertical timeline of professional journey.
    -   **Projects**: Showcase of featured work (currently "Coming Soon").
    -   **Contact**: Social links and email button.

## Technologies Used

-   **HTML5**: Semantic structure.
-   **CSS3**: Custom properties (variables), Flexbox, Grid, Animations, Backdrop Filter.
-   **JavaScript**: DOM manipulation for interactive background effects.

## Setup

1.  Clone the repository:
    ```bash
    git clone https://github.com/yourusername/portfolio.git
    ```
2.  Open `index.html` in your browser to view the site.

## Customization

-   **Colors**: Modify the CSS variables in `css/style.css` (`:root`) to change the color scheme.
-   **Content**: Update `index.html` with your own information.
